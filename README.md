# VitaHealth

Static wellness website built with HTML, CSS and JavaScript.

## Open the site

Double-click `index.html`, or from this folder:

```
npx --yes serve .
```

Then visit the local URL (https://impacterswebsite.netlify.app/).

## Pages

- `index.html` — landing page
- `shop.html` — product store with search, filters and cart
- `consultations.html`, `tracker.html`, `nutrition.html`, `subscriptions.html`, `appointments.html` — supporting UI pages

Cart is saved in the browser with `localStorage`. Product photos come from Unsplash.
